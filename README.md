# 道 (dao)

修仙题材挂机养成游戏的试玩版。当前阶段：**阶段 0 —— 单角色起步**。

- 玩：直接用浏览器打开 `index.html`（不需要构建、不需要服务器）。
- 开发工具：`v0.html` 是满编 5v5 战斗模拟器。
- 命令行：`node cli/stage0.js`（阶段 0 验收）、`node cli/battle.js`（单场日志）、`node cli/sim.js 1000`（批量模拟）、`node cli/experiments.js 1000`（V0 设计验证）。

文档：
- `docs/STAGE0_HANDOFF.md` —— 阶段 0 交接说明，从这里开始
- `docs/STAGE0_REPORT.md` —— 阶段 0 验收数据
- `docs/CHANGELOG.md` —— 变更记录
- `docs/HANDOFF.md`、`docs/DESIGN_QUESTIONS.md`、`docs/V0_SIM_REPORT.md` —— V0 交接、设计问题、模拟数据
