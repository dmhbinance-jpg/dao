# 道 (dao)

修仙题材挂机养成游戏的试玩版。当前阶段：**V0 —— 地基 + 战斗模拟器**。

- 直接用浏览器打开 `index.html` 即可（不需要构建、不需要服务器）。
- 命令行：`node cli/battle.js`（单场日志）、`node cli/sim.js 1000`（批量模拟）、`node cli/experiments.js 1000`（设计验证实验）。

文档：
- `docs/HANDOFF.md` —— 交接说明，从这里开始
- `docs/DESIGN_QUESTIONS.md` —— 模拟得出的设计问题
- `docs/V0_SIM_REPORT.md` —— 实验数据
- `docs/CHANGELOG.md` —— 变更记录
