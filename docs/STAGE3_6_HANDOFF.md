## 规则怎么落地
- **配置**
  - `CONFIG.game.production`：
    - `lines`：三条生产线 `forge` / `tailor` / `jewelry`，每条有名字、建筑名、打造值用的三维（`str` / `agi` / `int`）、2 个部位、`enabled`。本阶段只有 `forge` 开着。
    - `slotNames`：部位名。
    - `qualities`：6 档品质（id、名字、数值倍率）。
    - `qualityTables`：工坊等级 → 各品质概率（百分比），1 级先定，2–5 级占位。
    - `craft.statCoef`：打造时长系数。
  - `CONFIG.game.forge.recipes`：武器、胸甲各自的白品质基础数值、每件花费、基础时长。
  - 加新线的做法：在 `production.lines` 里把这条线设成 `enabled: true`，再在 `CONFIG.game.<线 id>.recipes` 里写这条线的部位配方。角色装备槽、属性加成、推荐都按已开放的线自动取部位。
- **装备**：`{ id, slot, quality, disabled? }`。数值不存档，按配置现算（基础数值 × 品质倍率，取整），调表后老装备跟着变。`gearUsable` 为假（部位所在的线没开、配方不存在，或者标了 `disabled`）的装备穿不上、不加属性，名字后面带「（暂不可用）」。
- **打造**（`Game.startCraft / tickCraft / cancelCraft`）
  - 任务存在 `save.crafting = { line, slot, charId, cost, durMs, progressMs, last }`，一次一件。
  - 时长在开工时按打造者当时的力算定：`baseSec × 1000 ÷ (1 + 力 × statCoef)`。
  - `tickCraft(save, now)` 按游戏时钟累加进度。页面打开时 `resumeCraft` 把 `last` 设成现在，所以离线不计算，和采集一样。
  - 到点时用独立的打造种子掷品质（`hashSeed('craft:' + craftSeed)`，每掷 +1），装备放进背包，`crafting` 清空，打造者变成闲置（不会自动回去采集或上阵）。
  - 取消退还全部材料。遣散打造中的角色会先取消打造。
- **派谁去**
  - 锻造页可以派闲置、采集中、上阵的人（唯一上阵的不行），默认挑闲置里力最高的，没有闲人就挑采集中力最高的。
  - 引导的默认顺序（`craftOptions`）：闲置里力最高的 → 招一位（3 选 1，`reason: 'craft'`，默认挑力成长最高的，选完直接开工）→ 调一个采集的人 → 从上阵里撤一个非开局角色。
- **状态优先级**：研究 > 打造 > 采集 > 上阵 > 闲置。打造中的人不能研究（`researchBlock = 'crafting'`）、不能采集、不能上阵。
- **推荐**（`nextUpgrade`）：背包里有比某个上阵角色身上更好（品质更高）的同部位装备 → 提示穿上；否则提示派人去打一个部位（先补上阵角色空着的部位，都有了就补品质最低的那个）。活动条提示、卡关「补装备」引导（一键：穿上能穿的、开工打下一件）、标准玩家模拟都用它。
- **引导**
  - `forge`（第一件装备）：灵矿和金币够打武器、并且有人可派时才弹，按 `craftOptions` 派人去打。
  - `equipFirst`：第一次打好装备时排队，默认把背包里最好的一件穿给最需要的上阵角色（`bestWearer`：这个部位空着或品质最低的）。
  - 全自动玩家之后的装备靠卡关「补装备」引导：每次确认就穿上背包里更好的、再开工打下一件。
- **洞府页实时刷新**：
  - 带 `data-live` 的数字（灵矿、金币、研究和打造的倒计时、进度条）每秒就地刷新。
  - 另外每秒算一次洞府状态签名（能不能招募 / 打造 / 研究、打造任务、谁在做什么、背包件数），变了就重画整页。所以金币、灵矿攒够时按钮会自己变成可点，又不会因为每秒重画而打断下拉框之类的操作。

## 观察到的问题（带回设计对话）
1. **打造者打完回到闲置**：按说明做的。标准玩家模拟会把闲人再派回采集，真实玩家和全自动玩家不会，所以全自动玩家调去打造的那个人之后就一直闲着。要不要「打完回到原来的岗位」？
2. **品质只看品质档**：同部位装备的好坏只按品质比较。以后有了词条或物品等级，比较规则要跟着改（`gearRank`）。
3. **锻造房等级和 2–5 级概率表**：都是占位，升级玩法以后做。
4. **打造时长和花费**：每件 40 秒基础时长、60 灵矿 / 150 金，都是占位，在配置网站「常用」里能直接调。
5. **研究列表的预计时长**按游戏时间显示，倒计时按真实时间显示（时间倍率不是 1 时两者不同）。要不要统一？
