## 3. 模拟玩家：从选角到打完第一段

策略见 cli/lib/play.js：自动推关（胜了打下一关；最新关输了退回最高已通关的关卡挂机；上阵角色升级后再挑战一次）。引导、3 选 1、首领确认各等 8 秒后确认（首抽免费 3 选 1 → 研究第 2 个上阵位 → 布阵 → 1-8 招人去采集 → 第一件装备 → 首领确认）。3 选 1 选默认（综合资质最高；为采集招募选力资质最高）。推关战斗按 2× 计时；挂机按 2× 计时、每场间隔 1.5 秒；研究按真实时间推进。每种开局 300 名玩家。
