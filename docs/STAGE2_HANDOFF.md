### 没通过的一条：金币结余
第二段收入约 4,500–6,200 金，标准玩家花掉约 3,600（额外招募 100 + 第 3 个上阵位 3,500），本段留存比例约 52–55%（阶段 1 几乎是 100%），但绝对结余仍从约 1,900 涨到约 3,900–4,400。全自动玩家不做可选研究，结余约 8,000。
- 原因：金币掉落随敌人等级线性增长，第二段一段的收入就比第一段的全部结余还多；而本阶段规定的出口只有两个（额外招募、第 3 个上阵位），又不调低掉落。
- 要让结余低于第一段结束时，第 3 个上阵位得卖到约 5,800 金，那样大多数人要到第二段打完才买得起，对本段没意义。
- 可选方向（等设计对话决定）：① 验收改成看「留存比例」；② 加金币出口（例如重掷收手续费）；③ 放宽「不调低掉落」，或让金币掉落随等级增长得慢一些；④ 接受现状，阶段 3 的锻造作为第三个金币出口（设计文档已写「招募、研究、锻造」）。

### 规则怎么落地
- **背包**：`save.bag = { cardId: 张数 }`。散卡没有数值，只显示名字、品质、标签、可用定位。
- **插卡**（`Game.insertCard`）：空槽 = 插入并掷数值；同名 = 重掷，`roll` 高的留下（我们的卡都是数值越高越好）；不同卡 = 换卡，旧卡直接销毁（界面先弹确认）。掷数值用独立种子 `hashSeed('roll:' + rollSeed)`，每掷 +1。只能插给 `card.roles` 里的定位。
- **第一张卡**：`cards.firstCardStage`（1-12）首次通关时按开局角色定位进背包，排队 `firstCard` 引导，确认就插给开局角色。
- **掉落**（`rollDrops`，不改存档）：只有 `cards.drops.chapters` 里的章节掉；每击杀一只非首领敌人，10% 掉一张「当前已插在角色身上的卡」的同名卡（重掷用），9% 从两种定位的卡池随机掉一张。种子由战斗种子派生，同种子同结果。战败照样掉已击杀的。
- **换卡选择计数**：掉落的卡如果对某个能用它的角色来说是「另一张卡」（他已经插了别的），记一次 `cardsInfo.swapOffers`。
- **招募自带卡**：拿到第一张卡之后招募的角色自带一张本定位的卡（优先和天赋标签匹配的），已插好、已掷数值。之前招募的不补。
- **首抽排除流影**：首抽的固有技能从池里去掉「流影」；之后的招募照常。
- **研究**：上阵位本阶段最多到 3（`research.slots.stageCap`）。第 3 级 3,500 金 / 基础 10 分钟。
- **额外招募引导**：2-3 首次通关后排队 `extraRecruit`，确认就花金币招一次（金币不够时不拦自动推关，继续挂机攒）。
- **卡牌提示**：掉落了能用的卡（可重掷 / 可插空槽 / 可换卡）就设 `bagNew`；`settings.cardPrompts` 打开时自动推关停下来。提示的默认动作「一键处理」只做重掷和插空槽，不替玩家换卡。背包页和提示框都能关掉这类提示。
- **第二段首领**：前排两只石甲猪，后排黑风狐王（血薄 ×0.5、伤害 +250%、开场护盾 30%）。狐王的固有技能「妖风阵」每隔一次行动给其他妖兽护甲 / 法抗 +60。穿云剑优先打后排、火雨打整个后排，都能直接打到狐王；狐王一死前排就好打了。

## 阶段 2 观察到的设计问题（带回设计对话）
1. **金币结余**：见上面「没通过的一条」。
2. **开局天赋改成标签型**：见上，需要在设计文档里确认或改回。
3. **战斗节奏和设计文档不一致**：文档第 15 节新写了「前期互秒，普通关 2–3 回合结束」，但现在（阶段 1 为了单段时长把气血加厚）普通关十来回合、首领 20 回合以上。长战斗里卡牌和首领机制的作用被稀释：调首领时，最初的设计（护盾 + 坦克前排）插卡完全没用，最后靠「狐王血薄、伤害高 + 给前排加甲」才让卡起作用。如果改成 2–3 回合，每段 10–15 分钟就需要多得多的战斗（或者更慢的播放节奏），阶段 0–2 的时长验收都要重做。建议设计对话先定：时长目标和战斗回合数哪个优先。
4. **阶段 1 招募的同伴不会自动拿到卡**：只能等第二段掉到本定位的随机卡来插空槽，部分玩家打完第二段同伴还是空槽（浏览器试玩里就出现了）。要不要在第一张卡之后补一个「给同伴插卡」的引导或固定掉落？
5. **主动卡和固有主动 CD 打架**：都是 CD 2、开场就绪，同时就绪时卡优先，固有主动的施放频率会被挤掉一些（实测插卡后固有主动的施放次数下降）。卡总体仍是增益，但比直觉小。
6. **第 3 个上阵位**：3,500 金 / 10 分钟，标准玩家约一半在第二段首领之前研究完。它是本阶段最大的金币出口，但对本段帮助有限。
7. **全自动玩家囤金**：不做可选研究，第二段结束时约 8,000 金。
