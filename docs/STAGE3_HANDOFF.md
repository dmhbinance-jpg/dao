### 规则怎么落地
- **存档 v4 新字段**：`ore`（小数）、`gather: { ids: [角色 id], last: 时间戳 }`、`gearBag: [装备]`、`nextGearId`、`unlocks.forge`，每个角色 `equip: { weapon, chest, ring }`。装备 `{ id, slot, tier, stat? }`，数值不存在存档里，按配置表现算（调表后老装备跟着变）。
- **采集**（`tickGather(save, now)`）：按 `now − gather.last` 结算，产量 = Σ 每人速率 × 秒数。界面每秒调一次，命令行在每次推进模拟时钟后调。**不补离线**：页面打开时 `resumeGather` 把 `last` 设成当前时间。派人 / 召回前先结算，速率变化不会算错。状态优先级：研究 > 采集 > 上阵 > 闲置。
- **资质系数** = 力成长 ÷ 3.0（开局剑修 = 1.0，下限 0.5）。法修普遍是 0.5，剑修 0.9–1.2。
- **锻造**（`forge(save, slot, tier, { stat })`）：扣灵矿和金币，装备进背包；界面里可以选「打好后给谁穿」，直接穿上。`equip(save, charId, gearId)` 可以从背包或别的角色身上拿，原来那件回背包。
- **推荐顺序**（`nextUpgrade`）：按上阵顺序 × 武器、胸甲、戒指，先把每个上阵角色补到中品，再往上品走；背包里有更好的直接穿（不花钱）。戒指默认加主属性（剑修力、法修智）。活动条提示、卡关引导、标准玩家模拟都用它。
- **引导**：
  - `gather`：第二段通关时排队（在 `done:heifeng` 之后）。默认派力资质最高的闲置角色；没有闲置时列出办法：招募一位（金币够、名额没满）→ 把研究中的人调来（`cancelResearch` 退还全部金币）→ 从上阵里撤一个非开局角色中等级最低的；按钮默认第一个，其余在弹窗里可选。
  - `forge`：采集引导确认后排队，灵矿和金币够第一件（下品武器）时才弹，打好给开局角色穿上。
  - `gearUp:<关卡>`：第三段在最新关战败时排队，灵矿和金币够下一件推荐装备时才弹，确认就按推荐一口气打完能打的；这关没过会留在队列里反复出现，过了自动移除。
  - `moreSlots`：第三段第一次卡关时，如果上阵位还能研究且没在研究，排队一次（金币够才弹），找闲置里智力最高的、其次采集中的人去研究。研究完如果没人采集了，重新排队 `gather`。
  - 这几个引导条件不满足时不弹窗、不拦自动推关；活动条显示第一件装备的灵矿进度。
- **第三段敌人**：铁背熊（力型，血 ×1.6、增伤 +80%、铁皮半档）、赤狐（远程法术，增伤 +80%）、铁背熊王（血 ×3.0、增伤 +100%、满档铁皮、山啸群伤）。难度从 3-1（不穿 Lv18 能过）逐关爬到 3-8（不穿 Lv27）；3-3「熊穴」是第一个明显卡住、需要装备的关。

## 阶段 3 观察到的设计问题（带回设计对话）
1. **全自动玩家只有 2 个上阵位**：他们不做可选研究，第二段结束时 2 人上阵 + 1 人闲置。只靠引导里那一件下品武器 + 卡关补装备，2 人满级（30）穿满上品也打不过 3-7 / 3-8。我加了一个卡关时「研究上阵位」的引导（会把采集的人调去研究，研究完再引导招人采集），全自动玩家因此 100% 打完，但他们这一段主要靠第 3 个上阵位和等级（Lv27），装备只有约 4 件。是否接受「卡关时引导研究上阵位」？还是让第二段就引导研究第 3 位？
2. **标准玩家采集的人基本靠招募**：第二段结束时标准玩家 3 人全上阵、没有闲置，采集引导 100% 走「招募一位」（约 150–340 金）。招到的定位随机，法修的采集系数只有 0.5，剑修约 1.0，所以第三段时长的离散有一部分来自这次招募的定位。要不要让「为采集招募」保底出剑修，或者资质系数不按力算？
3. **金币重新变成约束**：锻造价格（中品 1,300 金）定得比较高，才让标准玩家结余从约 4,000 降到约 3,000；灵矿和金币同时都在卡。全自动玩家不主动锻造，结余仍然约 14,000–15,000。
4. **中品够用，上品基本没人做**：标准玩家打完第三段时上阵角色平均 7 件装备、2 人全身中品，几乎没人打上品（上品 120 灵矿 / 3,000 金）。上品是后续阶段的目标还是这阶段就该出现？
5. **装备加成是扁平值**：等级越高，同一件装备的相对价值越低（Lv18 时中品武器约 +18% 攻击，Lv30 约 +12%）。后面如果出现更高等级的段落，白装需要按等级段分档或引入更高品质。
6. **装备给攻击时物攻法攻同时加**：一把武器剑修法修通用，方便换装，但设计文档没说。如果以后要分物理 / 法术武器，`recipes.weapon` 拆成两种即可。
7. **战斗节奏问题仍在**（见阶段 2 交接第 3 条）：第三段普通关十来回合，首领 20 回合左右。
