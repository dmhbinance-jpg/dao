- **调参覆盖**：`src/config/tuning.js`（`DAO.TUNING = { 路径: 值 }`）+ `src/config/apply-tuning.js` 在默认配置之后合并；file:// 和 Node 下都能用。命令行脚本也读它，加 `--defaults` 只用默认值，报告头写明用的数值。
- **时间倍率** `debug.timeScale`（1 / 2 / 5 / 10）：`src/game/clock.js` 游戏时钟 = 累加的「真实流逝 × 倍率」，不跳变；研究、采集、挂机、战斗播放都从它取时间；不改战斗结果。

- **`cli/lib/play.js`**：stage1/2/3 共用的模拟玩家；`cli/invariants.js` 新增时间倍率、招募 / 名额、调参三组检查。
- **存档 v5**：上一版（v4）自动迁移，递增招募价格状态丢弃；迁移链 v1 → … → v5。游戏页监听 storage 事件，存档在别的页面被改时自动重新读入。

## 阶段 3 —— 采集灵矿 + 锻造装备（2026-10-24）

闲置角色去采灵矿，灵矿 + 金币在洞府锻造房打造白装，装备成为新的战力来源，靠它通过第三段引导关。上阵、研究、采集共用同一批角色。

### 新增
- **采集**：第二段通关后洞府开放「采集」。角色随时派出、随时召回，不分班次，按秒连续产出：每秒 = 1.0 × 资质系数（力成长 ÷ 3.0，下限 0.5）。采集中的角色不能上阵、不能研究、不拿经验。离线不计算：重新打开页面从当时开始算，不补关闭期间的产出。召回后有空的上阵位自动上阵。
- **锻造房**：灵矿 + 金币即时打造，不占角色、没有建筑升级。3 个部位（武器加攻击、胸甲加护甲 + 气血、戒指加一项三维，打造时选），每个部位下品 / 中品 / 上品三档（20 / 50 / 120 灵矿，500 / 1,300 / 3,000 金）。只有白装、词条固定、不掉落。
- **装备**：每个角色 3 个装备槽，可以穿上、卸下、在角色间换；换下的、遣散角色身上的装备回装备背包。装备加成在战斗模型里生效（三维加在百分比天赋之前）。
- **第三段引导关「铁岩谷」**（8 关）：新敌人铁背熊（皮厚）、赤狐（远程高伤），首领铁背熊王。不穿装备要 Lv27 才能打完，穿一套中品白装 Lv21–22。
- **引导**：第三段开头引导派人采集（默认派力资质最高的闲置角色；没有闲置就列出「招募一位 / 把研究中的人调来（退还金币）/ 从上阵里撤一个」，默认第一个）→ 灵矿够了打第一件装备（下品武器给开局角色）。第三段卡关时引导「该去打装备了」（灵矿和金币够下一件时才弹，一键按推荐打造并穿上，这关没过会反复出现）和一次「研究上阵位」；研究完如果没人采集了，再引导一次采集。
- **活动条**：采集人数、总产量、灵矿；灵矿够打下一件时提示（不打断推关），可一键打造并穿上，可关掉。
- **界面**：顶栏灵矿；洞府页「采集」（每人每秒产量、系数、总产量、派出 / 召回）和「锻造房」（选部位、档位、戒指三维、打好后给谁穿、花费、数值预览与现穿对比、装备背包）；角色卡 3 个装备槽（穿戴 / 换 / 卸下）、采集速度；角色页「采集中」分组。
- **存档 v4**：阶段 2 存档（v3）自动迁移，打完第二段的直接开放采集 / 锻造房并弹采集引导；迁移链 v1 → v2 → v3 → v4。

### 新增
- **开局选角**：剑修或法修二选一，资质中等且固定，各带 1 条属性型天赋（力拔 / 慧根 +10%），不随机。开局角色和其他角色走同一套规则，没有主角特例。

## V0 —— 地基 + 战斗模拟器（2026-10-24）

### 地基
- **配置表** `src/config/`：所有数值集中在 `DAO.CONFIG` 一张表里，按文件分节：系数（`coef.js`）、普攻 / 固有主动 / 技能卡（`skills.js`）、天赋（`talents.js`）、示例角色与默认阵容（`characters.js`）。界面的「配置表」页可以直接改整张表并保存在本机。
- **带种子的随机数** `src/core/rng.js`：mulberry32。战斗里唯一的随机来源（暴击、随机目标、弹射、触发几率），同种子同阵容结果完全一样。
- **事件系统** `src/core/events.js`：开场、回合开始、出手时、暴击时、击杀时、受击时。带每回合次数上限和「触发不可递归」保护。
- **标签** `src/core/tags.js`：7 个标签（物理、法术、治疗、单体、群体、剑、火），形状标签由引擎按技能形状自动补上。
- **数据模型** `src/core/model.js`：角色模板（三维、2选1、技能卡档位、天赋档位）→ 战斗单位；阵容合法性检查。

### 战斗模块（`src/battle/`，不依赖界面，Node 可直接跑）
- 拉条：行动条按速度填充，满了出手；推条 / 拉条；CD 按角色自己的行动次数计。
- 双方各 5 人，前后两排、每排最多 3 人；近战单体只打前排，前排全灭后后排暴露；远程 / 穿透可打任意目标。
- 五种技能形状：单体、前排、后排、全体、弹射（随机命中 N 次、可重复、逐跳衰减）。
- 五个乘区：攻击×倍率 × (1+Σ增伤) × 暴击 × (1+Σ终伤) × k/(k+护甲或法抗)；buff 加算进各区，破甲最多减到 0；没有伤害随机浮动。
- 每个角色：普攻 + 固有主动（2选1）+ 主动卡槽 + 被动卡槽 + 1–3 条天赋（属性型 / 标签型 / 触发型）。
- 嘲讽、守护、护盾、治疗、增益 / 减益。
- 有界规则：再动每回合最多 1 次；触发不可递归；每单位每回合最多 3 次行动。
- 辅助贡献归因：把某个辅助施加的 buff / debuff 拿掉重算一遍伤害，差值记到施加者头上（减伤、破甲、增伤三项）。
- 批量模拟：胜率、平均回合、伤害占比、溢出、触发次数、技能每次伤害与变异系数、辅助贡献。可换边抵消先后手偏差。

### 示例角色（数值均为占位）

### 界面（`index.html`，直接用浏览器打开）
