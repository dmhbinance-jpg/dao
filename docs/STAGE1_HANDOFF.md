### 关键约定（沿用）
- 不用 ES modules；新文件同时加到 `index.html`（`v0.html` 如需要）与 `src/node.js`。
- 逻辑层不碰 DOM：`src/core`、`src/config`、`src/battle`、`src/game` 没有浏览器 API。涉及时间的规则函数都显式传 `now`（命令行传模拟时钟）。
- 所有数值进 `DAO.CONFIG`：阶段 1 的都在 `CONFIG.game`；气血公式在 `CONFIG.derive`。
- 随机只走 `DAO.RNG`：战斗用 `battle.rng`（种子 = 存档 `seedCounter`），招募用独立的招募种子（`hashSeed('recruit:' + gachaSeed)`，每抽 +1）。没有 `Math.random`。

### 规则怎么落地
- **1-4 卡关**：前排石甲猪（血厚、满档铁皮）+ 后排两只狐妖。剑修单人被狐妖磨死，法修单人被石甲猪顶死；两人 Lv4 能过，单人要 Lv8–9。在 1-4 第一次战败（或单人硬过）时开放洞府，并排队「cave」引导。
- **招募**：`Game.recruit(save, now)`。首抽免费、定位与开局角色互补；之后每日首次 100 金、每次 ×1.5、按本地日期重置。品质（凡 / 良 / 上 / 极，50 / 35 / 12 / 3%）决定成长倍率区间、天赋条数（1 / 1–2 / 2–3 / 3）、能否出触发型。天赋池用 V0 的（去掉治疗类和专属天赋），档位权重 60 / 30 / 10。等级 = 最高等级 − 1。有空的上阵位就自动上阵。名额满（12）时放进 `pendingRecruit`，弹窗让玩家遣散一个现有角色或遣散新人。
- **研究**：只有「上阵位」，`research.slots` 从 1 到 5。升第 2 级 20 金 / 60 秒，第 3 级 120 金 / 4 分钟……（`CONFIG.game.research.slots.levels`）。研究者离开上阵，时长 ÷ (1 + 智 × 1%)。完成后研究者有空位就自动上阵。
- **经验**：战斗中所有己方单位的击杀合起来算；每个上阵角色拿全额（`exp.split = true` 改为平分）。研究中、闲置的不拿。战败照样给已击杀的经验和金币。
- **布阵**：上阵到 2 人时自动排成剑修前、法修后（并排队「formation」引导），可在角色页单独换排或前后互换。1 人时不显示布阵，战斗里固定站前排。
- **自动推关**（`Game.autoDecide`，界面和命令行共用）：胜了打下一关；最新关输了退回最高已通关的关卡挂机；阵容签名（上阵角色 id + 等级）变化就再挑战一次最新关；首领关第一次、引导、名额已满时停下来等确认。研究引导如果金币不够，不停下，继续挂机攒钱。
- **引导链**（`Game.ackGuide`）：cave（免费招募）→ research（自动挑智力最高的闲置角色去研究）→ formation（应用默认站位）→ 首领确认 → chapterDone。弹窗可以点「稍后」，活动条上有按钮再打开。
- **存档 v2**：`localStorage['dao.save']`。第一次打开时若没有 v2 存档但有阶段 0 的 `dao.s0.save`（v1），自动迁移：开局角色等级 / 经验 / 种子 / 通关记录保留，补 60 金；打过 1-4 的直接开放洞府。旧键保留不删。

### 界面结构
- 顶栏：金币、上阵位（已上阵 / 已解锁）、自动推关开关、三个标签页。
- 活动条（顶栏下方，吸顶）：推关中 / 挂机进度 / 等待确认 + 研究倒计时。
- 关卡页：左边关卡列表（挑战、挂机），右边战斗回放 + 结算条。推关回放即使切到别的页也在后台继续，播完才结算。
- 洞府页：招募（价格、品质概率、最近一次结果）、研究（上阵位进度点、可派的角色和预计时长）。
- 角色页：布阵板（2 人以上）、按上阵 / 研究中 / 闲置分组的角色卡（三维与成长、技能、天赋、资质、上阵 / 下阵 / 遣散）。

## 阶段 1 观察到的设计问题（带回设计对话）
1. **金币大量结余**：第一段打完时手上约 1,800 金（P10–P90：1,500–2,200），但本阶段只有招募和研究两个出口，而且引导只用掉 20 金。是否在阶段 1 就鼓励多抽、研究第 3 个上阵位？还是金币掉落调低？
2. **招募品质的影响偏温和**：首抽资质最差 25% 只比最好 25% 慢 1–2.5 分钟、高 0–1 级。好处是不会卡死；但「资质有好坏」的感受可能不够强。要不要拉大品质间的成长差距？
3. **剑修开局比法修开局慢约 2 分钟**：差别主要在 1-4 之前的单人阶段（剑修单人推得慢），以及剑修开局时去研究的是法修招募角色。通关等级差 1 级，在要求内。
4. **站位反过来惩罚很重（平均差 59 个百分点）**：主要因为法修站前排会被近战集火；而剑修站后排并没有任何代价（近战照样出手）——V0 发现的「后排严格优于前排」在两人时仍然存在，只是被「法修太脆」掩盖了。按开发节奏留到阶段 4–5 处理。
5. **招募角色可能带「流影」**（穿透、优先打后排）：剑修招募有一半概率拿到，能绕开「剑修打不到后排」的教学点。目前影响的是法修开局的玩家（他们招到的是剑修），且只在 1-4 之后，问题不大；要不要限制首抽的固有技能？
6. **研究者自动挑选**：引导里自动选智力最高的闲置角色（通常是刚招到的人），开局角色继续打。也可以让玩家自己选——现在洞府页可以手动派，引导只是给了默认。
7. **全额经验**：每个上阵角色都拿全额，多一个上阵位等于经验翻倍。阶段 4–5 上阵位变多后，可能需要改成平分或部分平分（开关已留）。
